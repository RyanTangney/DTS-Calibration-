About
Calibrates Silixa XT/Ultima XML traces from the Stokes / anti-Stokes ratio, one trace at a time, against a reference section of known temperature.

T = γ / (ln(S/AS) + C − Δα·z)

The reference temperature can come from an RTD CSV (nearest timestamp) or from the probe readings stored in each XML.

All processing is local — no data leaves your machine.

Calibration settings
T(z) = γ / ( ln(Stokes / anti-Stokes) + C − Δα · z )  [kelvin]
C is solved for every trace so that section A reads its reference temperature: C = γ/TA − mean(ln S/AS) + Δα · mean(z).
Same model as your calibrate.m and DTS.m. Points where Stokes or anti-Stokes is ≤ 0 (noise, off the fibre) have no temperature.
γ is filled from the XML (TemperatureScalingFactor). The default Δα is the bare-fibre value from your calibrate.m. Change it, together with the section A / B LAF ranges above, to suit each cable and layout (e.g. 5.4e-5 is accepted).
Fibre section to keep in the output
Clip to your in-soil section. Leave blank for no limit. Beyond the fibre end, noise can pass the >0 test by chance and give wild temperatures, so clipping is worth doing.

DTScal
Silixa XML RTD probes Single-ended Fire science
Workflow
1DTS traces (ZIP) 2RTD probe CSVs 3Calibration config 4Export
About
Calibrates Silixa XT/Ultima XML traces using RTD probe measurements as dynamic reference bath temperatures.

Each DTS trace is matched to the nearest RTD timestamp. Gain and offset recalculate per trace.

RTD CSV must have a datetime column and a temperature column. Names are auto-detected.

All processing is local — no data leaves your machine.

One-point   : gain = 1  |  offset = RTD_A − mean_raw_A
