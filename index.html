About
Calibrates Silixa XT/Ultima DTS XML traces using single-ended reference bath method.

One XML file per trace. Outputs long-format CSV ready for R.

All processing happens in your browser — no data is uploaded to any server.

Bath A Calibration reference
Bath B Second reference (optional)
T_cal = gain × T_raw + offset
Two-point: gain = (T_B − T_A) / (T_raw_B − T_raw_A)  |  offset = T_A − gain × T_raw_A
One-point: gain = 1, offset = T_A − mean(T_raw in Bath A)
Cable section to retain
Clip output to your in-soil section. Reference baths and cable tails are excluded from the exported data. Leave as 0 / 9999 to keep all.
