About
Calibrates Silixa XT/Ultima XML traces using RTD probe measurements as dynamic reference bath temperatures.

Each DTS trace is matched to the nearest RTD timestamp. Gain and offset recalculate per trace.

RTD CSV must have a datetime column and a temperature column. Names are auto-detected.

All processing is local — no data leaves your machine.
